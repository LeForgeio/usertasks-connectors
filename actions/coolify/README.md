# Coolify

List, deploy and restart applications and manage their environment variables on a Coolify server.

Generated from `spec.json` by `npm run gen`. Do not edit this file by hand.

## Package and install

```bash
npm run package -- coolify --url https://coolify.example.com
```

Upload `release/coolify-1.0.0.zip` in UserTasks: **Extensibility > Workflow actions > Upload**. Then open **Manage > Access** on the action:

1. Approve the host.
2. Set the secret `api_token`. A Coolify API token. Create it in Coolify under Keys & Tokens, API tokens.

Recommended setup:

- Enable the API in Coolify: Settings, Configuration, Advanced, API Access
- Create an API token: Keys & Tokens, API tokens
- Give the token only the permissions it needs (read, write, deploy)

A token with the read permission cannot see sensitive values such as environment variable values.

## Operations

Every operation also returns `http_status`, `http_ok` and `response` (the full body). A status that is not 2xx fails the step (429 and 5xx can be retried).

| Id | Name | Call | Inputs (? = optional) |
|---|---|---|---|
| `list_applications` | List Applications | `GET /api/v1/applications` | `tag`? |
| `get_application` | Get Application | `GET /api/v1/applications/{{uuid}}` | `uuid` |
| `deploy` | Deploy Application | `POST /api/v1/deploy` | `uuid`, `force`? |
| `restart_application` | Restart Application | `POST /api/v1/applications/{{uuid}}/restart` | `uuid` |
| `list_deployments` | List Deployments of an Application | `GET /api/v1/deployments/applications/{{uuid}}` | `uuid`, `skip`?, `take`? |
| `list_envs` | List Environment Variables | `GET /api/v1/applications/{{uuid}}/envs` | `uuid` |
| `create_env` | Create Environment Variable | `POST /api/v1/applications/{{uuid}}/envs` | `uuid`, `key`, `value`, `is_preview`? |
| `update_env` | Update Environment Variable | `PATCH /api/v1/applications/{{uuid}}/envs` | `uuid`, `key`, `value`, `is_preview`? |

API reference: https://coolify.io/docs/api-reference/
