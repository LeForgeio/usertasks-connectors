# LeForge

Run LeForge actions and publish Fabric events from a workflow.

Generated from `spec.json` by `npm run gen`. Do not edit this file by hand.

## Package and install

```bash
npm run package -- leforge --url https://leforge.example.com
```

Upload `release/leforge-1.0.0.zip` in UserTasks: **Extensibility > Workflow actions > Upload**. Then open **Manage > Access** on the action:

1. Approve the host.
2. Set the secret `api_token`. A LeForge API key. It starts with fhk_. Create it in LeForge under Settings, API keys

Recommended setup:

- An API key made for this workflow engine only
- Scope actions:read to list actions. The connection test also needs it.
- The scope of each action the workflow runs
- Scope fabric:publish to publish Fabric events

A key gets its rights from the user who made it. Use a key from a user with the lowest role that works.

## Operations

Every operation also returns `status`, `ok` and `response` (the full body). A status that is not 2xx fails the step (429 and 5xx can be retried).

| Id | Name | Call | Inputs (? = optional) |
|---|---|---|---|
| `health` | Health | `GET /health` | - |
| `list_actions` | List Actions | `GET /api/v1/actions` | - |
| `run_action` | Run Action | `POST /api/v1/actions/{{action_id}}` | `action_id`, `input`?, `dryRun`? |
| `publish_event` | Publish Fabric Event | `POST /api/v1/fabric/events` | `type`, `payload`? |

API reference: https://github.com/LeForgeio/leforge
