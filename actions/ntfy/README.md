# ntfy

Send push notifications to phones and desktops through an ntfy server.

Generated from `spec.json` by `npm run gen`. Do not edit this file by hand.

## Package and install

```bash
npm run package -- ntfy --url https://ntfy.example.com
```

Upload `release/ntfy-1.0.0.zip` in UserTasks: **Extensibility > Workflow actions > Upload**. Then open **Manage > Access** on the action:

1. Approve the host.
2. Set the secret `api_token` (optional: leave it empty for a server that allows anonymous calls). Optional. Leave empty for a server that allows anonymous publish. Create it on the server with: ntfy token add <user>

Recommended setup:

- A topic for each alert stream
- An access token with write access to those topics (ntfy token add)

A public server such as ntfy.sh needs no token, but anyone who knows the topic name can read it.

## Operations

Every operation also returns `status`, `ok` and `response` (the full body). A status that is not 2xx fails the step (429 and 5xx can be retried).
