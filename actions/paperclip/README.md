# Paperclip

Create tasks, add comments, change task status and wake agents in a Paperclip company.

Generated from `spec.json` by `npm run gen`. Do not edit this file by hand.

## Package and install

```bash
npm run package -- paperclip --url https://paperclip.example.com
```

Upload `release/paperclip-1.0.0.zip` in UserTasks: **Extensibility > Workflow actions > Upload**. Then open **Manage > Access** on the action:

1. Approve the host.
2. Set the secret `api_token`. An agent API key (bearer token). Create an agent key in Paperclip. Do not use a board admin key.

Recommended setup:

- An agent API key made for this workflow
- Only the rights the workflow needs. Each template needs its own right: create tasks, comment, change status, wake agents.

Do not use a board admin key. The key can act in the company it belongs to.

## Operations

Every operation also returns `http_status`, `http_ok` and `response` (the full body). A status that is not 2xx fails the step (429 and 5xx can be retried).

| Id | Name | Call | Inputs (? = optional) |
|---|---|---|---|
| `create_issue` | Create Issue | `POST /api/companies/{{company_id}}/issues` | `company_id`, `title`, `description`?, `priority`?, `assignee_agent_id`, `status`? |
| `get_issue` | Get Issue | `GET /api/issues/{{issue_id}}` | `issue_id` |
| `add_comment` | Add Comment | `POST /api/issues/{{issue_id}}/comments` | `issue_id`, `body` |
| `update_issue_status` | Update Issue Status | `PATCH /api/issues/{{issue_id}}` | `issue_id`, `status` |
| `wake_agent` | Wake Agent | `POST /api/agents/{{agent_id}}/wakeup` | `agent_id`, `reason`? |

API reference: https://github.com/paperclipai/paperclip
