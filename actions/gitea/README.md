# Gitea

Manage repositories, issues, pull requests, commit statuses and Actions runs on a Gitea server.

Generated from `spec.json` by `npm run gen`. Do not edit this file by hand.

## Package and install

```bash
npm run package -- gitea --url https://git.example.com
```

Upload `release/gitea-1.0.0.zip` in UserTasks: **Extensibility > Workflow actions > Upload**. Then open **Manage > Access** on the action:

1. Approve the host.
2. Set the secret `api_token`. A personal access token for the user that makes the calls Gitea > Settings > Applications > Generate New Token

Recommended setup:

- A personal access token from a dedicated bot user
- Scopes: read:user, read:repository, write:repository, write:issue (add read:organization for organization repositories)
- Add the bot user as a collaborator only on the repositories it must change

Create the token in Settings > Applications. Use read-only scopes when the flow only reads.

## Operations

Every operation also returns `status`, `ok` and `response` (the full body). A status that is not 2xx fails the step (429 and 5xx can be retried).

| Id | Name | Call | Inputs (? = optional) |
|---|---|---|---|
| `get_repository` | Get Repository | `GET /api/v1/repos/{{owner}}/{{repo}}` | `owner`, `repo` |
| `list_issues` | List Issues | `GET /api/v1/repos/{{owner}}/{{repo}}/issues` | `owner`, `repo`, `state`?, `labels`?, `page`?, `limit`? |
| `create_issue` | Create Issue | `POST /api/v1/repos/{{owner}}/{{repo}}/issues` | `owner`, `repo`, `title`, `body`?, `label_ids`? |
| `comment_on_issue` | Comment on Issue or Pull Request | `POST /api/v1/repos/{{owner}}/{{repo}}/issues/{{index}}/comments` | `owner`, `repo`, `index`, `body` |
| `close_issue` | Close Issue | `PATCH /api/v1/repos/{{owner}}/{{repo}}/issues/{{index}}` | `owner`, `repo`, `index` |
| `list_pull_requests` | List Pull Requests | `GET /api/v1/repos/{{owner}}/{{repo}}/pulls` | `owner`, `repo`, `state`?, `page`?, `limit`? |
| `get_pull_request` | Get Pull Request | `GET /api/v1/repos/{{owner}}/{{repo}}/pulls/{{index}}` | `owner`, `repo`, `index` |
| `create_pull_request` | Create Pull Request | `POST /api/v1/repos/{{owner}}/{{repo}}/pulls` | `owner`, `repo`, `head`, `base`, `title`, `body`? |
| `set_commit_status` | Set Commit Status | `POST /api/v1/repos/{{owner}}/{{repo}}/statuses/{{sha}}` | `owner`, `repo`, `sha`, `state`, `context`?, `description`?, `target_url`? |
| `list_actions_runs` | List Actions Runs | `GET /api/v1/repos/{{owner}}/{{repo}}/actions/runs` | `owner`, `repo`, `page`?, `limit`? |

API reference: https://docs.gitea.com/api/1.26/
