# Home Assistant

Read entity states, call services, fire events and send phone notifications through Home Assistant.

Generated from `spec.json` by `npm run gen`. Do not edit this file by hand.

## Package and install

```bash
npm run package -- home_assistant --url https://ha.example.com
```

Upload `release/home_assistant-1.0.0.zip` in UserTasks: **Extensibility > Workflow actions > Upload**. Then open **Manage > Access** on the action:

1. Approve the host.
2. Set the secret `api_token`. Profile page > Security > Long-lived access tokens > Create token

Recommended setup:

- A long-lived access token from a dedicated user
- A user that can control only the entities the workflows need

A long-lived access token has the full rights of its user. Create it in your profile page, under Security.

## Operations

Every operation also returns `status`, `ok` and `response` (the full body). A status that is not 2xx fails the step (429 and 5xx can be retried).

| Id | Name | Call | Inputs (? = optional) |
|---|---|---|---|
| `api_status` | API Status | `GET /api/` | - |
| `get_state` | Get State | `GET /api/states/{{entity_id}}` | `entity_id` |
| `list_states` | List States | `GET /api/states` | - |
| `call_service` | Call Service | `POST /api/services/{{domain}}/{{service}}` | `domain`, `service`, `data`? |
| `fire_event` | Fire Event | `POST /api/events/{{event_type}}` | `event_type`, `event_data`? |
| `render_template` | Render Template | `POST /api/template` | `template` |

API reference: https://developers.home-assistant.io/docs/api/rest/
